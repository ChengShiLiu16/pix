审查当前 git 暂存区的代码变更。运行 `git diff --cached` 获取变更内容。

重点审查：

1. **正确性** — 逻辑错误、边界未处理、空指针/undefined 风险、竞态条件
2. **安全** — 注入(XSS/SQL/命令)、敏感信息泄露、未校验的输入
3. **性能** — 不必要的循环/递归、O(n²) 可优化为 O(n)、内存泄漏、多余渲染
4. **健壮性** — 错误处理是否完整、异常路径是否考虑、资源是否正确释放
5. **可维护性** — 命名是否清晰、函数是否过长、是否有重复逻辑

输出格式：
- 按严重程度排列：🔴 必须修复 → 🟡 建议修改 → 🟢 可选优化
- 每个问题给出：文件位置、问题描述、修改建议（给出代码片段）
- 如果没有问题，明确说"未发现问题"

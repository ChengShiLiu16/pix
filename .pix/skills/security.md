---
description: 快速查找代码中的安全漏洞
argument-hint: "[目录路径，默认当前目录]"
---

对 ${@:-.} 进行安全审计。

重点检查：

1. **注入攻击** — SQL 注入、命令注入、XSS、模板注入
2. **认证/授权** — 硬编码密钥、未校验 token、权限绕过
3. **数据泄露** — 敏感信息写日志、错误信息暴露内部细节、API 返回过多数据
4. **加密** — 弱算法(MD5/SHA1)、硬编码 secret、不安全的随机数
5. **输入校验** — 未校验的外部输入(用户输入/URL参数/API请求体)
6. **依赖安全** — 已知漏洞的依赖版本

输出格式：
- 🔴 高危：可被直接利用
- 🟡 中危：需要特定条件才能利用
- 🟢 低危：信息性风险
- 每个问题给出：文件位置、攻击向量、修复方案（代码片段）

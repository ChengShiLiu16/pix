description: 生成或更新 API 接口文档
argument-hint: "<文件路径或模块名>"
---

为 $@ 生成 API 文档。

步骤：

1. 完整阅读源文件，识别所有导出的函数/类/类型
2. 为每个导出项生成文档，包括：
   - 功能说明（中文）
   - 参数说明（名称、类型、是否必填、默认值）
   - 返回值类型和说明
   - 使用示例（代码片段）
   - 注意事项（副作用、边界情况）
3. 输出为 Markdown 格式

约束：
- 文档必须与代码实际行为一致，不要凭想象编写
- 类型信息从 TypeScript 类型定义获取，不要手动抄写
